# История изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).
Новые изменения записываются в «Не выпущено». `make release` переносит их в раздел новой версии.

## [Не выпущено]

## [0.4.0] — 2026-11-16

### Добавлено
- **Лимиты Claude только через VPN** (Настройки → Claude, включено по умолчанию). Перед запросом проверяется, что маршрут до `api.anthropic.com` идёт через VPN-туннель (`utun`, `ipsec`, `ppp`, `tun`, `wg`; подходит для Happ, WireGuard, Outline, IKEv2 и других) или через системный прокси VPN-клиента. Когда соединение установлено, но запрос с токеном ещё не отправлен, проверяется, что оно идёт с адреса туннеля. Если нет, соединение закрывается, и токен не уходит. Без VPN в панели написано «Нет VPN: запрос к Claude не отправлен», а когда VPN подключается, лимиты обновляются сами.

### Изменено
- Редактирование заметок стало заметнее: при наведении на заметку появляется кнопка ✏️, в контекстном меню есть пункт «Редактировать», а поля названия и пунктов в редакторе выглядят как поля ввода. Изменения сохраняются сами.

## [0.3.0] — 2026-11-13

### Добавлено
- **Полка для файлов.** Начинаешь тащить файл, и под маяком в статус-баре появляется окошко «Положи сюда». Брошенный файл копируется на полку (на APFS мгновенно, без лишнего места на диске). Файлы можно вытаскивать с полки по одному или все сразу за заголовок, после этого копия удаляется. Двойной клик открывает файл. Пока на полке что-то лежит, в статус-баре виден счётчик 📎N, а в панели кнопка «Полка». Настройки: Инструменты → Полка для файлов (показывать при любом перетаскивании или только у верхнего края экрана).
- Анимации полки. Она выезжает из-под статус-бара и проявляется, содержимое раскрывается пружиной, а при скрытии полка уходит вверх с затуханием. Когда над полкой держат файл, зона приёма увеличивается, пунктир «бежит», иконка подпрыгивает, на трекпаде чувствуется отклик. Файлы появляются и исчезают с анимацией, размер окна меняется плавно.

## [0.2.1] — 2026-11-12

### Исправлено
- Смена статуса в трекере падала с ошибкой 422 «Вы должны указать значения для полей comment». Теперь для таких переходов появляется поле комментария с готовым текстом («Готово к тестированию», «Готово к ревью», «Взял в работу»…). Текст можно поправить, отправка по ↩. Приложение запоминает, какие переходы требуют комментарий, и в следующий раз сразу показывает поле с последним использованным текстом для этого статуса.

## [0.2.0] — 2026-11-11

### Добавлено
- **Яндекс Трекер.** Вкладка «Задачи» с фильтрами «В работе», «Ждут», «Мои», «События». В карточке задачи: смена статуса, списание времени (15м / 30м / 1ч / 2ч / своё значение с комментарием), таймер, комментарии, копирование ключа, ветки и ссылки.
- Уведомления трекера: назначили на меня, призвали, новый комментарий, смена статуса. Свои действия не уведомляются.
- Таймер задачи и число непрочитанных событий в статус-баре (`⏱1:05 ●3`).
- Вход в трекер по OAuth-токену (живёт около года), токен хранится в Keychain. Тот же токен подходит для MCP трекера в Claude Code, авторизация больше не слетает каждые 12 часов.
- Настройка статусов во вкладке «Мои». По умолчанию от «Беклога» до «В работе» включительно.
- Шаблон имени ветки: `{key}`, `{slug}`, `{type}`.
- **Заметки и чеклисты.** Новая вкладка «Заметки». Быстрый ввод (`[] пункт; пункт` создаёт чеклист), пункты отмечаются прямо в списке, закреплённые заметки видны в «Сводке», заметку можно привязать к задаче трекера.
- Вкладка «Сводка»: таймер, трекер, только упавшие и идущие пайплайны, лимиты Claude.
- Отладочная отрисовка панели в PNG (`BEACONHUB_SNAPSHOT_DIR`), подмена файла заметок (`BEACONHUB_NOTES_FILE`).
- Публикация релизов на GitHub: `make release`.

### Изменено
- Панель разбита на вкладки, чтобы не превращаться в длинное полотно.
- При пяти вкладках показываются только подписи, без иконок, чтобы ничего не переносилось.

### Исправлено
- Ссылки в комментариях трекера стали кликабельными: и markdown-ссылки, и голые URL.
- Запросы к трекеру идут по очереди, после ответа 429 делается пауза: трекер ограничивает параллельные запросы.
- В «Сводке» было «1 проектов», теперь «проектов: 1».

## [0.1.0] — 2026-11-11

Первая версия.

### Добавлено
- Приложение для статус-бара macOS 14+ с всплывающей панелью.
- **GitLab CI/CD.** Статусы пайплайнов выбранных проектов. Токены подхватываются из `glab`, поддерживается несколько хостов, включая self-hosted. Можно добавить хост вручную с Personal Access Token. Есть уведомления об упавших и успешных пайплайнах.
- **Лимиты Claude** (5 часов и неделя) по токену Claude Code из Keychain, процент выводится в статус-баре.
- **Текст с экрана** (⌘⇧2): OCR на русском и английском, распознавание QR-кодов.
- **История буфера обмена** (⌥⌘V): поиск, закрепление, вставка сразу в поле, пароли из менеджеров паролей не сохраняются.
- Скрипты сборки: `make install`, `make dev`, `make package` (universal zip).

### Исправлено
- Панель растёт по содержимому до предела, дальше появляется скролл.
- Первое распознавание текста казалось зависшим: модель теперь прогревается при запуске, а ход работы показывается во всплывающих сообщениях.
