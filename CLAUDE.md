# Beacon Hub

Приложение для статус-бара macOS (Swift / SwiftPM, без Xcode-проекта). Устройство и команды описаны в README.md.

## Правила
- **Каждое изменение записывай в `CHANGELOG.md` → «Не выпущено»** (Добавлено / Изменено / Исправлено), сразу по ходу работы, человеческим языком.
- Новые сборки выпускаются только через `make release` (`BUMP=minor` или `V=x.y.z`). Скрипт ставит тег `vX.Y.Z` и публикует GitHub Release с zip в https://github.com/shuraman69/beacon-hub. Версию в `VERSION` руками не меняй.
- Репозиторий публичный: никаких токенов, ID организаций, логинов и почты в коде, логах и тестовых данных.
- Перед выпуском проверяй, что `make install` собирается, а вёрстка нормально отрисовывается через `BEACONHUB_SNAPSHOT_DIR`.
